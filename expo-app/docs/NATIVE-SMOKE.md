## GitHub Actions alternative (prepared only)

Root `.github/workflows/android-smoke.yml` is manual only and accepts a required existing Expo EAS APK URL. The validator permits only exact `https://expo.dev/artifacts/eas/<identifier>.apk` paths with no query, fragment, shell syntax, alternate host or credentials. It downloads an existing binary and never starts an EAS build. The fixture must use the isolated backend embedded in that binary. Repository read-only checks returned PUBLIC, ADMIN viewer permission, Actions enabled and all actions permitted on 2026-10-04. No workflow was pushed or triggered in this preparation pass.

Lead creates fresh confirmed-email fixture secrets `DROPS_NATIVE_QA_EMAIL` and `DROPS_NATIVE_QA_PASSWORD` in GitHub, using the same empty-state preconditions below, then pushes and manually dispatches the workflow after the APK completes. GitHub secrets become only `MAESTRO_EMAIL`/`MAESTRO_PASSWORD` process environment variables, never CLI arguments. The display name is generic `Native QA`. One Ubuntu 24.04 hosted API35 Pixel6 emulator runs, with a 35-minute job limit and no retries or local emulator. The action is pinned to ReactiveCircus v2 commit `a421e43855164a8197daf9d8d40fe71c6996bb0d`; Maestro is pinned to CLI2.11.0 and its release ZIP SHA256 is checked. All helper actions are pinned to commits.

`scripts/native-smoke.mjs` captures Maestro output without printing it, directs raw debug/reports to a temporary workspace, copies only three named post-login screenshots and constructs a fixed-field result summary. It deletes raw temporary artifacts afterward. The upload step targets only `artifacts/native-smoke-safe`, retaining artifacts for three days; raw failure screenshots, logs, command JSON and reports are never uploaded. A failed login produces a generic phase/status summary without credential text. This makes failure diagnosis deliberately limited. If the hosted runner is terminated before cleanup, its ephemeral raw workspace is still outside the artifact upload path. No credential values exist in prepared source or local artifacts.
